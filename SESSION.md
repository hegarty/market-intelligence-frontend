## Decisions / gotchas the next session shouldn't have to rediscover

1. **Next.js 16 has real breaking changes vs. training-era knowledge.**
   `AGENTS.md` (auto-regenerated by `next dev` — don't hand-edit it, edit
   around it) says to read `node_modules/next/dist/docs/` before assuming
   v15-era APIs. `cacheComponents` is **off** (default) — the app uses plain
   client components + TanStack Query, not `"use cache"`/Suspense. `params`
   in page components is a `Promise`; pages use the generated
   `PageProps<'/chart/[symbol]'>` helper type and `await props.params`.

2. **TanStack Table is v9, not v8** — a genuinely different API
   (`useTable` + explicit `tableFeatures({...})` registration; no
   `useReactTable`/`getCoreRowModel()`). If you need to touch table code,
   run `npx @tanstack/intent@latest list` / `load <skill>` in this repo
   first rather than trusting v8-shaped examples. Shared feature set lives
   in `src/components/tables/features.ts`.

3. **TradingView's free widget restricts cash indices and continuous
   futures** when embedded from an unregistered domain — `TVC:VIX`,
   `COMEX:GC1!`, `NYMEX:CL1!`, `TVC:US10Y`, `TVC:TNX` all fail with "This
   symbol is only available on TradingView." Verified empirically (scripted
   Playwright checks against the real widget, not assumed). Fixed via proxy
   symbols in `src/lib/market-data/fixtures/assets.ts` (`AMEX:VIXY`,
   `TVC:GOLD`, `TVC:USOIL`) — see the comments there and
   `docs/tradingview-integration.md#symbol-availability--verified-not-assumed`
   before "fixing" those mappings back to the obvious symbol.

4. **This eslint-config-next enforces stricter react-hooks rules than
   usual** — `react-hooks/set-state-in-effect` flags synchronous `setState`
   calls inside `useEffect` bodies (including the common
   `useEffect(() => setMounted(true), [])` hydration pattern), and
   `react-hooks/refs` flags ref reads/writes during render. Fixed via a
   shared `useSyncExternalStore`-based `useHasMounted()` hook
   (`src/hooks/useHasMounted.ts`) and, in `TradingViewChart`, an "adjust
   state during render" pattern (compare a derived `configKey` against the
   previously-rendered one, `setState` conditionally in the render body)
   instead of resetting state inside the effect. If a new component needs
   mount-detection or reset-on-prop-change state, follow these patterns
   rather than re-adding the naive effect version.
